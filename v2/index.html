Custos que valem para todos os produtos

Os quatro primeiros são vinculados ao vivo: mudar aqui recalcula na hora todos os produtos, sem reeditar um por um. A exceção são os produtos que você destravou manualmente no formulário — esses ficam congelados e aparecem com a tag "custo alterado".

Backup dos dados

Os dados ficam no banco de dados. O backup em JSON é uma cópia extra, para guardar onde você quiser. Restaurar troca o catálogo inteiro da empresa (só o dono ou o administrador).

Situação

Conflitos juntados

Itens que você e outra pessoa alteraram ao mesmo tempo. Nada foi descartado: nos campos que os dois mudaram ficou o seu valor, e aqui dá para trocar pelo da outra pessoa.

Histórico de alterações

Papéis

  • Dono — tudo, inclusive incluir e tirar pessoas e gerar senha nova.
  • Editor — altera produtos, preços, marketplaces, custos e o Mercado Livre.
  • Leitor — só consulta.

Quem ainda não tem conta recebe uma senha provisória, que aparece uma vez só aqui. No primeiro acesso o sistema pede para a pessoa criar a senha dela.

Se a pessoa já tem conta (trabalha em outra empresa), ela entra com a senha que já usa.
