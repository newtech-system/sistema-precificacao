Passo a passo (uma vez só)

Isso cria uma planilha Google que funciona como banco de dados. Leva uns 5 minutos e você faz isso uma única vez.

  1. Crie uma planilha nova em sheets.google.com -- pode ser em branco, o sistema cria as abas sozinho.
  2. No menu, vá em Extensões → Apps Script.
  3. Apague o conteúdo do arquivo Code.gs que abrir e cole o código abaixo no lugar.
  4. Clique em Implantar → Nova implantação. Em "Tipo", escolha App da Web.
  5. Em "Executar como", deixe Eu (seu e-mail). Em "Quem pode acessar", escolha Qualquer pessoa -- isso é obrigatório, senão o navegador não consegue falar com o script.
  6. Clique em Implantar, autorize as permissões pedidas (é o Google pedindo confirmação de que você mesmo está rodando seu próprio script) e copie a URL do app da Web gerada.
  7. Cole essa URL no campo acima e clique em Conectar.

Se você editar o código do Apps Script depois, precisa fazer Implantar → Gerenciar implantações → editar (ícone de lápis) → Nova versão para as mudanças valerem -- só salvar o arquivo não atualiza a URL publicada.

Reaproveitando isso para vários clientes

Não existe forma de gerar automaticamente a planilha e a URL de um clique só -- isso depende da conta do Google de cada cliente e a Deploy do Apps Script não é copiada junto quando você duplica uma planilha (limitação do próprio Google, não deste sistema). Mas dá pra reduzir os 7 passos acima a só 3 depois da primeira vez:

  1. Faça a configuração da aba acima uma única vez, numa planilha que vai virar seu "modelo mestre".
  2. Para cada cliente novo: abra o modelo mestre e faça Arquivo → Fazer uma cópia -- o código do Apps Script vai junto automaticamente na cópia.
  3. Na cópia, ainda assim é preciso repetir só o passo de implantar: Implantar → Nova implantação → App da Web (o código já está lá, só falta gerar a URL própria desse cliente) e colar a URL nova nesse arquivo HTML entregue a ele.

Isso garante que os dados de cada cliente ficam isolados em planilhas separadas, o que aliás é o correto -- uma URL só compartilhada entre clientes misturaria os produtos de todo mundo numa única planilha.

Código para colar no Apps Script

Este código mudou na versão atual do sistema (ganhou as colunas variableFixedFee e mktFixedFee). Se a sua planilha já estava conectada, cole o código novo por cima do antigo e publique uma nova versão da implantação existente — Implantar → Gerenciar implantações → lápis → Versão: Nova versão.
