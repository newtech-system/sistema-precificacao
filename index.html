Histórico de alterações

Passo a passo (uma vez só)

Isso cria uma planilha Google que funciona como banco de dados. Leva uns 5 minutos e você faz isso uma única vez.

  1. Crie uma planilha nova em sheets.google.com -- pode ser em branco, o sistema cria as abas sozinho.
  2. No menu, vá em Extensões → Apps Script.
  3. Apague o conteúdo do arquivo Code.gs que abrir e cole o código abaixo no lugar.
  4. Clique em Implantar → Nova implantação. Em "Tipo", escolha App da Web.
  5. Em "Executar como", deixe Eu (seu e-mail). Em "Quem pode acessar", escolha Qualquer pessoa -- isso é obrigatório, senão o navegador não consegue falar com o script.
  6. Clique em Implantar, autorize as permissões pedidas e copie a URL do app da Web gerada.
  7. Cole essa URL no campo acima e clique em Conectar.

Se você editar o código do Apps Script depois, precisa fazer Implantar → Gerenciar implantações → editar (ícone de lápis) → Nova versão para as mudanças valerem -- só salvar o arquivo não atualiza a URL publicada.

Reaproveitando isso para vários clientes

Não existe forma de gerar automaticamente a planilha e a URL de um clique só -- isso depende da conta do Google de cada cliente, e a implantação do Apps Script não é copiada junto quando você duplica uma planilha (limitação do próprio Google). Mas dá pra reduzir os 7 passos acima a só 3 depois da primeira vez:

  1. Faça a configuração da aba acima uma única vez, numa planilha que vira seu "modelo mestre".
  2. Para cada cliente novo: abra o modelo mestre e faça Arquivo → Fazer uma cópia -- o código do Apps Script vai junto.
  3. Na cópia, repita só o passo de implantar: Implantar → Nova implantação → App da Web, e entregue a URL nova a esse cliente.

Isso mantém os dados de cada cliente isolados em planilhas separadas -- uma URL compartilhada misturaria os produtos de todo mundo.

Código para colar no Apps Script

Este é o código versão 5. Além de tudo da versão 4 (produto pai com um anúncio por marketplace, faixas de preço, trava de gravações simultâneas), ele grava o histórico de alterações (aba Historico: quem mudou o quê e quando), percebe quando alguém edita a planilha à mão — e faz os dispositivos lerem e juntarem essa edição antes de gravar, em vez de apagá-la — e recusa páginas antigas do sistema que ainda estejam abertas em algum computador. A versão 4 continua funcionando, mas sem histórico e sem essa proteção. Para atualizar: cole o código novo por cima do antigo e publique uma nova versão da implantação existente — Implantar → Gerenciar implantações → lápis → Versão: Nova versão. A URL continua a mesma.
